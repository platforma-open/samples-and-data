Warns, on the metadata page and on every dataset page, when blocks that use data of this block no longer find it — an output it does not export or values it no longer has — and suggests adding the data or reconfiguring those blocks. The warning shows in desktop versions that compute links between blocks.
Built with SDK 1.88.0 (workflow-tengo 6.20.0, block-tools 2.17.5, tengo-builder 4.1.17).
